# 我最喜欢的三本书

|  #  | 书名                       | 作者    |   分类    |
| :-: | :----------------------- | :---- | :-----: |
| 🥇  | [[《蒙田随笔》-蒙田|蒙田随笔]]      | 蒙田    | B9-哲学宗教 |
| 🥈  | [[《悲惨世界》-雨果|悲惨世界]]      | 雨果    | B1-文学虚构 |
| 🥉  | [[《独居的一年》-约翰·欧文|独居的一年]] | 约翰·欧文 | B1-文学虚构 |

- **蒙田随笔** — 随笔文体开创者，以"我知道什么？"为座右铭，直面人性真实
- **悲惨世界** — 人类苦难与救赎的史诗，仁爱 Versus 法律的永恒冲突
- **独居的一年** — 欧文式叙事，在荒诞与温情中讲述时间如何治愈一切
