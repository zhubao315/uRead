# 财务自由路径规划

## 核心定义

财务自由是指被动收入覆盖生活支出的状态，无需为钱工作。

## 财务自由公式

```
财务自由 = 被动收入 ≥ 生活支出
```

## 路径规划

### 1. 评估现状

| 评估项 | 计算 |
|--------|------|
| **年支出** | 月支出 × 12 |
| **储蓄率** | (收入-支出)/收入 |
| **投资收益率** | 年投资收益/总投资额 |

### 2. 目标设定

| 阶段 | 目标 |
|------|------|
| **财务安全** | 6个月应急基金 |
| **财务自主** | 1年生活费储蓄 |
| **财务自由** | 25倍年支出投资 |

### 3. 实现策略

| 策略 | 说明 |
|------|------|
| **增加收入** | 提升主业、副业 |
| **控制支出** | 降低生活成本 |
| **提高储蓄率** | 目标>30% |
| **投资增值** | 长期投资 |

### 4. 投资配置

| 阶段 | 配置 |
|------|------|
| **积累期** | 80%股票+20%债券 |
| **保全期** | 60%股票+40%债券 |
| **享用期** | 40%股票+60%债券 |
