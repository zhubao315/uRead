# uRead 品牌方向：Editorial Reading Library

## 定位

uRead 是**个人阅读档案与知识沉淀平台**（Personal Reading Library）。

- 中文口号：让读过的书，留下值得反复阅读的内容。
- 英文口号：READ · REFLECT · REVISIT
- 核心价值：阅读有记录，思想有脉络，知识可重访。

它不是电子书阅读器、AI 聊天工具、通用知识管理 SaaS 或统计 Dashboard。AI 只是未来可能的后台能力，当前真实价值是已积累的内容资产。

## 内容层级

书籍是源头 → 笔记是核心 → 书单是策展 → 主题是探索路径。四者是多对多关系，不是四个平级菜单；视觉上应像一座持续生长的私人图书馆。

## 气质关键词

知性（Intellectual）、克制（Minimal）、现代（Modern）、编辑感（Editorial）、结构化（Structured）、可持续（Timeless）。

避免：过度科技感、机器人/大脑/星光符号、大面积渐变、Glassmorphism、过多阴影、统计卡墙、过度圆角、无意义动画。

## 色彩方向

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| Deep Navy | `#17243A` | 标题、正文、品牌深色 |
| Reading Blue | `#2457A6` | 主交互、按钮、链接 |
| Active Blue | `#477FE8` | 悬停与交互强调 |
| Mist Blue | `#DCE8F8` | 专题、标签、浅色区块 |

比例：70% 中性背景/白色，20% 深蓝与品牌蓝，7% 雾蓝，3% 书签金。

## 字体方向

中文标题 Noto Serif SC（思源宋体），中文正文 Noto Sans SC（思源黑体），英文 Inter / Manrope，数字与元信息 Inter。阅读正文行高 1.75–1.9，桌面正文宽 680–760px，手机自适应留白。

## Logo 概念

U + Open Book + Bookmark：字母 U 构成外轮廓，两片书页形成打开的书，中间负空间为书脊，金色书签代表阅读痕迹。要求原创、几何、无渐变/阴影，16px 下可识别，黑白可用。

## 图标与组件

统一 Lucide 风格线性图标：24px 基准、2px 线宽、圆角端点，不混用 Emoji。按钮主色品牌蓝、次要白色/浅蓝、删除语义红；卡片白底细边框极轻阴影；圆角 6/10/14px；动画 150–200ms 且尊重 reduced-motion。
