# uRead 响应式规范

## 断点

| 设备 | 宽度 | 布局 |
| --- | --- | --- |
| 手机 | 360 / 375 / 390 / 430 | 单列；搜索首屏可见；底部导航首页/笔记/书单/书籍；触控 ≥44px |
| 平板 | 768 / 1024 | 双列；侧栏可折叠；封面比例统一 |
| 桌面 | 1280 / 1440 / 1920 | 编辑式网格；正文宽 680–760px；留白充分 |

## 原则

1. 移动端不是桌面缩小版：重新组织信息，标题与摘录优先。
2. 不出现横向滚动、文字截断、图片变形、导航遮挡。
3. 移动端底部导航不遮挡内容，工作台作为独立入口。
4. 阅读正文行高 1.75–1.9，左右留白，文字不贴边。
5. 书单单列或横向滑动，封面比例固定。
6. 搜索结果按书籍/笔记/书单/主题分组，不用巨型卡片。

## 当前落地

- Navbar：移动端 3 列、sm 5 列；共 5 项。
- 首页：`lg:grid-cols-[1.15fr_.85fr]` Hero，书单 md 2 列 / xl 3 列，书籍 sm 2 列 / lg 3 列。
- 笔记正文：`.note-article` 最大 46rem，摘录/理解/延伸分区。
- 底部导航：本轮尚未实现（任务书阶段 5 后续项），当前使用现有响应式 Navbar，不应误报已实现。
