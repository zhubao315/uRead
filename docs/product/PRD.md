## 定位

uRead 是**个人读书笔记与主题书单库**（Personal Reading Library & Book Notes）：
以书籍为索引、以读书笔记为核心、以主题书单为导航。
口号：让读过的书，留下值得反复阅读的内容。

内容资产以 `docs/migration/content-inventory.json` 为准，不在文档里写死数量；
每次结构变更后必须重新运行 `npm run content:inventory` 对账。

## 三个核心对象

- **书籍 BOOK**：内容索引。书名、作者、封面、阅读状态、全部笔记、所属书单。
- **读书笔记 NOTE**：核心资产。摘录、理解、方法、页码、来源、标签。
- **书单 BOOKLIST**：内容导航。主题、推荐理由、书目顺序、关联笔记。

主题阅读作为书单的一种类型或专题分类保留，原始主题数据不删除、不合并。

## 产品边界

建设：读书笔记 / 书籍资料 / 书单推荐 / 主题阅读 / 全文搜索 / 内容详情 / 内容关联 / 阅读记录 / 公开内容发布。
保留为辅助：知识卡片、音频、EPUB/PDF 静态书库。
本轮不建设：AI Agent、RAG、向量库、复杂知识图谱、云端账号、多用户协作。

## 信息架构

公开内容站默认首页；管理工作台独立入口。

- 公开：`/`（内容门户）、`/notes`、`/booklists`、`/books`
- 兼容：`/read`、`/themes`、`/lists`、`/books/`、`/docs/` 继续有效
- 管理：`/library`、`/cards`、`/booklists` 本地数据区、`/search` 及备份/同步

路由兼容硬约束见 `docs/migration/route-map.md`；`/books/` 是真实静态目录，新的书籍详情路径不得覆盖它。

## 数据保全（最高优先级）

1. 原始笔记、书单、主题、书目顺序、推荐说明、wikilink、别名逐项保留。
2. 新增展示层索引，不覆盖原始内容；原有 ID、路径、内容哈希保留。
3. 同名书籍只列候选，不自动合并；未关联笔记不丢弃；无法解析内容保留并报告。
4. 迁移前后按基线逐项核对，数量或哈希减少即停止发布。

基线：`publishing/content-baseline.json`；保全规则：`docs/migration/data-preservation-plan.md`。

## 验收指标

- 内容完整性：原始笔记 / 书单 / 主题 100% 保留，哈希一致。
- 内容可发现性：书籍、笔记、书单、主题统一搜索并分组显示。
- 内容关联性：从书籍详情能看到它的全部笔记。
- 使用效率：主要内容三步内可达。
- 阅读体验：手机与桌面都能舒适阅读。
